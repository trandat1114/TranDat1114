# Archive guide

The public account contains coursework, visual experiments, utility prototypes, and forks accumulated over time. They are retained for history and attribution, not removed during this rebrand.

## Current engineering direction

Start with the pinned repositories and the FLAGSHIP / ENGINEERING LABS sections in the profile README. Those repositories are maintained as the clearest public record of current .NET, backend, systems, and database-performance learning work.

## Legacy presentation

The following groups are intentionally treated as historical rather than flagship work:

- older games, visual demos, and one-off frontend experiments;
- coursework and early full-stack prototypes;
- forks and copied training repositories;
- repositories without a current README or maintenance intent.

No repository was deleted or hidden as part of this presentation change. A repository can move out of the archive only when its documentation, runnable state, and scope make it useful to a reader today.
